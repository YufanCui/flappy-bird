# Improvement round 2 结果记录（2026-11-18 训练，11-19 00:00 评估完成）

**原则：** 题目（环境）不变，始终是随机开口 80–120（原始 reward，原游戏水平间距）。新 baseline 是 E3 中最好的
`gap80_120+stack4`（叠加 4 帧，1M steps）。每个变体只在 baseline 上加 **一个** 改动，seeds 0、1、2，计划在训练前写好（见 `PLAN.md`）。
评估：最终 checkpoint，deterministic，同一组 20 个 episode seeds（230000–230019），每局上限 10,000 步（约 264 根柱子，称为“飞满”）。
数字 = 平均完整穿过的柱子数。

## 1. 做了什么改动 / 增加了什么 randomness
- 环境的 randomness **没有变**：开口大小在 80–120 中随机（每对新柱子独立抽一次），开口中心在 8 个位置中随机。
- 改的都是 **小鸟一方（训练方法）**：learning rate 衰减、curriculum、entropy bonus、更大的网络、更多训练量。

## 2. 结果（主要评估环境：随机开口 80–120）

| 变体 | 唯一的改动 | 平均 | seeds 0/1/2 | 结论 |
|---|---|---:|---|---|
| baseline `stack4_1M`（E3） | — | 22.7 | 32.8 / 21.2 / 13.9 | 参照 |
| `_lr` | learning rate 从 3e-4 线性衰减到 0 | **49.9** | 57.9 / 51.5 / 40.1 | ✅ **大幅变好**（×2.2），3 个 seeds 全部高于 baseline 最好的 seed |
| `_cur` | curriculum：前 50% 训练中开口从 120 逐渐放宽到 80–120 | 12.2 | 18.6 / 3.6 / 14.3 | ❌ 变差 |
| `_ent` | ent_coef 0.01（鼓励探索） | 13.6 | 14.0 / 19.9 / 6.8 | ❌ 变差 |
| `_big` | 网络 128×128（默认 64×64） | 9.4 | 10.0 / 14.9 / 3.2 | ❌ 变差 |
| `_3M` | 训练量 1M → 3M（常数 learning rate） | 14.3 | 33.2 / **0.0** / 9.8 | ❌ 没有变好；seed 1 的最终 policy 完全崩溃（所有环境都是 0） |

## 4. 解读（哪些有证据，哪些是推测）
1. **LR 衰减是本轮唯一有效的改动，而且效果很大。** 证据：3 个 seeds 都在 40 以上（baseline 最好的 seed 是 32.8）；
   在固定开口 100 上 42% 的局飞满 10,000 步。训练曲线（`progress.jsonl`）显示：其他变体的训练分数一直在 0–15 根之间波动，
   而 `_lr` 的 3 个 seeds 在最后 10 万步（learning rate 接近 0）都明显上升（21 / 20 / 36）。
   **推测**的机制：常数 learning rate 让 policy 在“学会”之后继续大幅更新，表现不断被破坏；衰减后 policy 在后期稳定下来。
2. **常数 learning rate 下，训练更久没有用，甚至危险。** 3M 的 seed 1 在训练分数上反复跌到 0，最终 policy 在所有环境都是 0 分。
   这与第 1 点一致：问题不在训练量，而在训练不稳定。
3. curriculum、entropy、大网络都变差。只用 3 个 seeds、1M steps，不能说它们“一定没用”，只能说在这个设定下没有帮助。
4. **仍然没有在随机开口 80–120 上飞满过**（最好一局 165 根）。更窄的开口 60–79 所有方法都接近 0（见 E1 的可行性讨论）。
5. 这些都是 development 评估（同一组 episode seeds 被反复使用），还不是 final test。
