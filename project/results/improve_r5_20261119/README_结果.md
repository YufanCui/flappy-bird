# Round 5 结果记录（2026-11-19 22:34 评估完成）

预先登记见 `PLAN.md`（训练前写好）。

## 1. 做了什么改动
- **环境不变：** 开口随机 80–120 + 5% sticky actions（`gap80_120+sticky5`），原版 reward。
- **agent 改动（两个假设）：**
  - H1 信息不足 → `prevact`：把“上一步实际执行的动作”加进 observation（181 维）。
  - H2 训练不够 → 训练 10M steps（之前 3M）。
- 全部：stack4 + learning rate 线性衰减，seeds 0–2。
- **评估：** 最终 checkpoint，deterministic，episode seeds 230000–230019，每局上限 40,000 步（约 1,061 根）。对照为 Round 4 `_orig`（同环境、同评估，3M，无 prevact）。

## 2. 增加了什么 randomness
没有新增。沿用 Round 4：开口随机 + 5% 按键延迟。

## 3. 结果（平均完整穿过的柱子数；括号 = 飞满 40,000 步的比例）

| 训练方式 | **开口随机 + 延迟（主要）** | 开口随机 | 原游戏 | 原游戏 + 延迟 |
|---|---:|---:|---:|---:|
| Round 4 对照：3M | 20.1（21.8 / 18.6 / 19.8） | 100.4 | 771.2（48%） | 47.0 |
| H1：+prevact，3M | 20.3（23.9 / 21.4 / 15.6） | 127.0 | 779.1（52%） | 47.7 |
| H2：10M | 21.1（20.1 / 23.1 / 20.1） | **173.3** | **1007.4（88%）** | **63.7** |
| H1+H2：+prevact，10M | 21.3（16.8 / 22.4 / 24.6） | 139.8 | 793.7（62%） | 49.1 |

- 10M 在原游戏上 3 个 seeds 都很高：1009.5 / 970.0 / 1042.5（之前 3M 是 1055.7 / 607.9 / 650.0）。
- 主要条件下最好一局：74–157 根，平均始终在 20 根左右。

## 4. 改动有没有帮助？
1. **H1（prevact）在主要条件下没有帮助**：20.3 vs 20.1，seeds 重叠。
2. **H2（10M）在主要条件下也没有帮助**：21.1 vs 20.1，seeds 重叠。
3. **但 10M 在没有延迟（或延迟 + 固定开口）的条件下有明显提升**：原游戏 771 → 1007（88% 飞满），开口随机 100 → 173，原游戏 + 延迟 47 → 64。所以更长的训练确实让 agent 变强了，只是这种“变强”没有转化为对 5% 延迟的抵抗力。
4. prevact + 10M 没有比单独 10M 更好（原游戏 seed 1 只有 477，seed 间差异大）。

## 5. 解读与推测（未验证）
- 主要条件下的约 20 根，**在 3M→10M、加不加 prevact 之间都几乎不变**，而其他条件下性能大幅变化。这说明瓶颈不是“训练量”或“缺少上一步动作的信息”。
- 精确上限（`../theory_sticky_v1_20261119/`）显示最优策略可以在前 500 根中平均通过约 425 根。所以差距仍然来自 agent。
- **推测**：PPO 学到的是“贴着边缘飞”的高效策略，没有为一次意外的延迟留出安全余量；而最优策略会刻意留余量。这可以通过比较 agent 和最优策略在柱子入口处的高度分布来检验，目前没有做。
- 局限：每组 3 seeds；development 评估；只测了 deterministic 策略。

## 6. 下一步候选（给老师讨论）
- 检验“安全余量”假设（agent vs DP 最优策略的高度分布）。

- recurrent policy；或用 DP 最优策略做 imitation / 作为 teacher。
