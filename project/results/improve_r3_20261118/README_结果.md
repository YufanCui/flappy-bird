# Improvement round 3 结果记录（2026-11-19 01:20 评估完成）

**原则：** 题目（环境）不变：随机开口 80–120（原始 reward，原游戏水平间距），spec `gap80_120+stack4`。计划在训练前写好（`PLAN.md`）。
评估：最终 checkpoint，deterministic，同一组 20 个 episode seeds（230000–230019），每局上限 10,000 步（约 264 根，称为“飞满”）。
数字 = 平均完整穿过的柱子数。

## 1. 做了什么改动 / 增加了什么 randomness
- 环境的 randomness **没有变**（开口 80–120 随机，开口中心随机）。
- 改的是训练方法：(a) 在**新 seeds 3–5** 上重复 round 2 的 learning rate 线性衰减，并配同 seeds 的 baseline 对照；
  (b) learning rate 线性衰减 + 训练量 3M（seeds 0–2）。

## 2. 结果

### (a) 复现：新 seeds 3–5，1M steps
| 变体 | 随机开口 80–120 | seeds 3/4/5 | 原游戏（开口 100，飞满比例） | 更宽 121–140（飞满比例） |
|---|---:|---|---:|---:|
| baseline（不衰减） | 16.3 | 18.6 / 15.9 / 14.4 | 31.1（0%） | 131.3（15%） |
| LR 线性衰减 | **71.9** | 73.5 / 76.4 / 65.7 | **229.8（78%）** | 128.1（30%） |

✅ **复现成功**：3 个 LR seeds 全部远高于 3 个 baseline seeds（最低 65.7 vs 最高 18.6）。随机开口上第一次出现飞满的局（5%）。

### (b) LR 衰减 + 3M，seeds 0–2
| 变体 | 随机开口 80–120 | seeds 0/1/2 | 原游戏（飞满比例） | 更宽 121–140（飞满比例） |
|---|---:|---|---:|---:|
| LR 衰减 1M（round 2） | 49.9 | 57.9 / 51.5 / 40.1 | 162.6（42%） | 147.9（32%） |
| LR 衰减 3M | **92.1** | 96.2 / 110.9 / 69.2 | **225.4（73%）** | **202.5（60%）** |

✅ **LR 衰减时，训练更久继续有效**：每个 seed 都比 1M 版本高（同一个 seed 比较：+38 / +59 / +29）；随机开口上 8% 的局飞满。
对比 round 2：**常数** learning rate 的 3M 只有 14.3，且一个 seed 崩溃。

更窄开口 60–79 仍然全部接近 0（所有变体都是）。

## 3. randomness 有没有改善作用？
本轮没有新增 randomness，回答的是“在开口随机的环境里，怎样让鸟飞得更远”。

## 4. 解读
1. **LR 线性衰减是目前最可靠的改进**：两组不同的 seeds（0–2 和 3–5）都得到了大幅提升，不是碰巧。
2. **训练量要配合 LR 衰减才有用**：常数 LR 时 3M 不比 1M 好；衰减时 3M 比 1M 高约 85%。
3. 随机开口 80–120 上目前最好：**平均 92.1 根，8% 的局飞满 10,000 步**。离“每局都飞满”还有距离。
4. 局限：每组只有 3 个 seeds；仍是 development 评估（episode seeds 被反复使用），不是 final test；
   LR 衰减为什么有效（后期 policy 更新变小、更稳定）是推测，还没有直接验证。
