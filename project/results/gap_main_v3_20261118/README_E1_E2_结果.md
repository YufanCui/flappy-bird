# E1 / E2 结果记录（2026-11-18）

设计见 `PLAN.md`（训练前登记）。共 15 个 models，每个 model 在 5 个评估条件 × 2 种 action 模式（deterministic / stochastic）× 20 局上评估，合计 3,000 局。
数字 = 完整穿过的柱子数（pipes_cleared），先对每个 training seed 的 20 局取平均，再对 5 个 seeds 取平均；方括号是 5 个 seeds 各自的平均值。
“完美局” = 飞满 10,000 步上限仍未撞（约 264 根柱子）。

---

## E1：开口随机（老师要求的 randomness）

**改了什么：** 只改训练环境里上下两根管之间的开口大小。
- 对照组 `gap100_100`：开口永远是 100 px（= 原游戏）。
- 实验组 `gap80_120`：每生成一对新 pipe，从 80–120 px 中均匀随机抽一个整数作为开口（平均仍为 100）。

**增加的 randomness：** vertical gap size 从常数变成随机变量 G ~ U{80, …, 120}，每对 pipe 独立抽取。

**保持不变：** 原始 reward（flappy-bird-gymnasium 0.4.0，proximity −0.5）、原游戏的水平间距（144/144/164）、开口中心高度的分布与随机序列、LiDAR observation、PPO 默认超参数、训练量 301,056 steps、seeds 0–4。

**结果（deterministic）：**

| 评估环境 | 固定开口训练 | 随机开口训练 | 哪组更好 |
|---|---|---|---|
| 原游戏（开口 100） | **48.5** [42.1, 35.4, 27.4, 92.7, 44.8] | 23.0 [27.0, 3.9, 23.8, 30.4, 29.7] | 固定组 |
| 随机开口 80–120 | 10.3 [15.3, 9.2, 6.3, 10.8, 10.1] | **14.2** [17.1, 3.7, 13.6, 17.0, 19.6] | 随机组（+38%） |
| 更宽 121–140（训练外） | 68.8 | **78.9** | 随机组（seed 差异极大） |
| 更窄 60–79（训练外） | 0.1 | 0.4 | 两组都几乎飞不过 |
| 随机开口 + 随机间距 | **7.3** | 6.9 | 接近 |

Stochastic 模式下方向基本一致：随机开口环境 7.9 vs **8.5**；原游戏 **19.1** vs 15.1；更宽 33.0 vs **51.0**。

**结论：**
1. **随机开口让任务变难很多。** 固定组在原游戏上平均 48.5 根，换到随机开口环境只剩 10.3 根。
2. **在随机开口环境里，用随机开口训练更好：** 14.2 vs 10.3。5 个 seeds 中有 4 个高于固定组的大多数 seeds；但 random 组 seed 1 只有 3.7，差异尚不足以做显著性结论。
3. **代价：** 随机组在原游戏（固定开口）上明显变差（23.0 vs 48.5），是典型的“专门化 vs 泛化”取舍：固定组擅长它见过的固定环境，随机组更能应对变化。
4. **开口 < 80 时两组都几乎失败**（每局不到 1 根）：这超出了训练范围，而且这一 reward 下小开口还附带不可避免的 proximity penalty（见 `diagnostics_v1` 的 feasibility 分析）。
5. **离“飞不停”还很远：** 随机开口环境中没有任何一局飞满 10,000 步，最好的一局 44 根。

**randomness 有没有帮助？** 如果目标是“在有不确定性的环境里飞得更好”，**有帮助**（+38%，方向在 deterministic 和 stochastic 下一致）。如果目标是“在原游戏里飞得最远”，**没有帮助**，反而减半。

## E2：再增加一种 randomness（开口随机 + 水平间距随机）

**改了什么：** 在 E1 随机开口组的基础上，再让前后两对 pipe 之间的水平距离也随机。

**增加的 randomness：** horizontal spacing D ~ U{120, …, 180} px（平均 150，与原游戏平均 150.7 接近），每对 pipe 独立抽取，与开口大小用不同的随机流。

**保持不变：** 与 E1 随机组完全相同（reward、开口分布、observation、PPO、训练量、seeds）。

**结果（deterministic）：**

| 评估环境 | E1 随机开口训练 | E2 开口+间距随机训练 |
|---|---|---|
| 开口+间距都随机（E2 自己的训练环境） | 6.9 | 6.2 |
| 随机开口 80–120 | **14.2** | 9.4 |
| 原游戏 | **23.0** | 14.2 |
| 更宽 121–140 | 78.9 | **118.4**（16% 的局飞满上限） |

**结论：**
1. 双随机的环境最难：所有组在这里都只有约 6–7 根。
2. 在 300k steps 内，**多加一个随机变量没有带来提升**：E2 组在自己的训练环境上（6.2）并不比 E1 组（6.9）或固定组（7.3）好，在其他环境上也大多更差。
3. 唯一的例外是更宽的开口（118 根，最高）。但这个条件最简单，差异也落在 seed 的波动范围内。
4. **解读：** 随机性越多，同样的训练量越学不会。这提示瓶颈在于学习能力（训练量、observation 缺少速度信息），这正是 E3 要检验的。

**randomness 有没有帮助？** 在当前训练量下，**额外的间距随机没有帮助**。
